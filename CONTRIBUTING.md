# Contributing

Contributions are welcome for defensive detection logic, synthetic datasets, ATT&CK mappings, explainability, tests, and safe integrations.

1. Create a feature branch.
2. Add tests for behavior changes.
3. Run `pytest -q`.
4. Open a pull request with a concise description.

Do not contribute exploit code, credential-harvesting functionality, destructive actions, or automation against systems you do not own or have explicit authorization to test.
